# 🦝 Bayoung Exopet — Digital Storefront & Portfolio

Website resmi **Bayoung Exopet** yang dirancang khusus sebagai **Digital Storefront + Brand Portfolio + Lead Generation** untuk bisnis studio hewan eksotis dan penyedia perlengkapan *wood pellets* di Malang, Jawa Timur.

Sistem transaksi tetap berjalan **offline** dan personal, sementara website berfungsi sebagai pusat edukasi, portofolio kredibilitas, dan katalog interaktif yang menghubungkan calon pemelihara (*keeper*) langsung ke WhatsApp admin.

## ✨ Fitur Utama

- **Branding & Visual Ungu Khas Bayoung:** Menggunakan warna ungu royal, aksen lilac, tipografi modern, ornamen *sparkle* (✦), dan footer *deep dark purple*.
- **Maskot & Logo Resmi:** Ikon maskot huruf **B** dengan siluet Musang Pandan, Otter, Kelinci, dan Hamster.
- **Hero Section:** Tagline *"Meet Your ✦ Exotic Companion."*, Musang Pandan di atas kayu alami dengan doodle panah tulisan tangan, serta floating badge *"Small Creatures Big Joy 🐾"*.
- **Our World Bar:** Navigasi cepat 5 kategori hewan (*Musang, Otter, Rodent, Rabbit, Other*).
- **Available for Adoption:** Katalog adopsi tanpa tombol cart. Tombol *"View Details ➔"* membuka modal spesifikasi lengkap (karakter, pola makan, usia, kesehatan, syarat adopsi) dan tombol direct WhatsApp dengan template pesan otomatis.
- **Quality Supplies (Wood Pellets):** Showcase kemasan standing pouch *"BAYOUNG WOOD PELLETS"* dengan doodle kaligrafi, beserta katalog grid perlengkapan (*Wood Pellets, Food & Nutrition, Habitat & Enclosure, Accessories*).
- **Dual Promo Cards:**
  - *Exotic Pet Guide:* Panduan pemula merawat Musang, Otter, dan panduan penggunaan wood pellets.
  - *Join Our Community:* Integrasi WhatsApp Group dan mockup smartphone feed Instagram (@bayoung.exopet).
- **Live Search & Filter:** Modal pencarian cepat untuk menemukan hewan dan produk.
- **Informasi Kontak & Lokasi Studio:** Terintegrasi alamat studio di Pakisaji, Kab. Malang beserta link Google Maps.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik, aksesibilitas, dan SEO meta tags.
- **Vanilla CSS3:** Design tokens kustom, responsive breakpoints, glassmorphism, dan animasi mikro.
- **JavaScript (ES6+):** Logika katalog dinamis, modal handler, generator pesan WhatsApp terenkripsi, dan carousel navigation.
- **Node.js:** Server static ringan bebas dependensi eksternal.

## 🚀 Cara Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/ryuukage-byte/bayoung.git
   cd bayoung
   ```

2. Jalankan server lokal:
   ```bash
   node server.js
   ```

3. Buka di browser:
   ```text
   http://localhost:3000
   ```
   *(Atau klik ganda file `index.html` langsung di browser favorit Anda)*
